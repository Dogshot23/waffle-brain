# WaffleBrain Prompt Architecture

## Purpose

Every WaffleBrain prompt follows exactly the same structure.

The engine determines the conversation mechanic.

The world determines the theme.

The CEFR level determines the language demand.

Nothing else changes.

---

# Prompt Structure

Every prompt contains six sections.

1. Hook
2. Ask
3. Teacher
4. Quick
5. Stuck
6. Constraint

---

# 1. Hook

The Hook introduces an interesting situation.

Its job is to create curiosity immediately.

It should be visual.

It should be short.

It should naturally fit the chosen World.

Examples

• Three robots arrive at your school.
• A dragon steals your backpack.
• Scientists discover a new planet.
• A detective finds one strange clue.

The Hook never explains the whole situation.

---

# 2. Ask

The Ask starts the engine.

This is the only part the teacher absolutely needs to read aloud.

The Ask should immediately trigger the engine mechanic.

Examples

Keep One

"Which one do you keep?"

Convince Me

"Convince me."

Rank It

"Put these in order."

Build Together

"Let's build it together."

The wording should stay as consistent as possible.

---

# 3. Teacher

The Teacher section explains how to run the engine.

This is written for teachers only.

Students never read it.

It explains:

• pacing
• follow-up questions
• how to keep the engine alive
• how to avoid ending the conversation too early

Every prompt using the same engine should have almost identical Teacher instructions.

---

# 4. Quick

Quick is the first rescue prompt.

Use it if the student answers too quickly.

It should naturally extend the conversation without changing the engine.

Examples

"What happens next?"

"Why?"

"What changes now?"

"What would happen tomorrow?"

Quick should always keep the original engine running.

---

# 5. Stuck

Stuck is the emergency rescue.

Use it if the student cannot answer.

It should reduce the cognitive load.

Usually this means:

• fewer choices
• a simpler decision
• a yes/no choice
• a forced choice between two options

Stuck should never introduce a different activity.

It should rescue the current engine.

---

# 6. Constraint

The Constraint defines the language target.

This is not shown to students.

It tells the teacher what language should naturally emerge.

Examples

A1/A2

• because
• can
• going to

B1

• comparatives
• should
• might
• could

B2+

• conditionals
• justification
• persuasion
• counterarguments

---

# Golden Rule

Every prompt is built using the same architecture.

Only these things change:

• World
• CEFR level
• Scenario

The engine structure never changes.
