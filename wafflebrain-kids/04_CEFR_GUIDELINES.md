# WaffleBrain CEFR Guidelines

The engine NEVER changes between CEFR levels.

Only the language demand changes.

A teacher should be able to run exactly the same engine with an A1 learner and a B2 learner.

---

# A1/A2

Goal

Build confidence.

Students should speak often using familiar grammar.

Language

• Present Simple
• can
• because
• going to
• basic adjectives
• simple comparisons

Teacher

Keep the pace fast.

Accept short answers.

Use rescue prompts early.

Topics

Concrete.

Visual.

Funny.

Immediate.

---

# B1

Goal

Extend conversations.

Students begin defending ideas and making predictions.

Language

• comparatives
• should
• might
• could
• opinions
• simple speculation

Teacher

Ask follow-up questions.

Challenge weak answers.

Push for examples.

Topics

Slightly more abstract.

More reasoning.

Longer conversations.

---

# B2+

Goal

Develop sophisticated spoken English.

Students defend positions, justify ideas and handle counterarguments.

Language

• conditionals
• hypothetical situations
• nuanced opinions
• persuasive language
• speculation
• abstract discussion

Teacher

Challenge assumptions.

Play devil's advocate.

Introduce complications.

Expect evidence and justification.

Topics

Ethics.

Society.

Technology.

Science.

Psychology.

Current issues.

---

# Golden Rule

Do NOT change the engine.

Increase or decrease only:

• vocabulary
• grammar
• cognitive demand
• abstraction

The conversation mechanic always remains identical.
