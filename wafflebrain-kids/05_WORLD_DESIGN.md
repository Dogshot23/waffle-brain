# WaffleBrain World Design

## Purpose

Worlds provide the theme.

Engines provide the gameplay.

A World should never change how an engine works.

Changing the World only changes the vocabulary, setting and imagination.

# Rules for Creating New Worlds

A World is NOT an engine.

A World is simply a collection of themes.

Every engine must work inside every world.

If an engine cannot naturally work inside a world, the world is badly designed.

---

# Good World Test

A good World allows all 10 engines to operate naturally.

For example:

Keep One

Build Together

Twist It

Emoji Spark

Rank It

Convince Me

One Change

Clue Drop

Bad Choices

Wild Theory

should all feel equally natural.

---

# Bad Worlds

Avoid worlds that are too small.

Bad:

• Football
• Harry Potter
• Dinosaurs
• Minecraft

These quickly run out of ideas.

---

# Good Worlds

Choose worlds that contain hundreds of possible topics.

Good:

• Animals
• Science
• Nature
• Food
• History
• Space
• Mythology
• Crime
• Movies
• Inventions
• Cities
• Jobs
• Emotions

---

# Expansion Rule

New content is created by adding Worlds.

Never by inventing new engines.

The engines are permanent.

The worlds are unlimited.
