# WaffleBrain Prompt Checklist

Every new Waffle prompt must pass every check below.

---

# Engine

□ It clearly belongs to ONE engine only.

□ A teacher can identify the engine in under 5 seconds.

□ It does not accidentally introduce another engine.

---

# Mechanics

□ The mechanic never changes.

□ Only the theme changes.

□ The rules stay identical across every prompt using that engine.

---

# Hook

□ Starts immediately.

□ Interesting within the first sentence.

□ No unnecessary explanation.

---

# Teacher Instructions

□ Match the canonical teacher instructions for that engine.

□ No custom mechanics.

□ No unnecessary variation.

---

# Quick Rescue

□ Gives the teacher one fast follow-up.

□ Keeps the conversation alive.

---

# Stuck Rescue

□ Makes the task easier.

□ Never changes the engine.

□ Reduces cognitive load.

---

# Language

□ Appropriate for the CEFR level.

□ Natural spoken English.

□ No awkward wording.

---

# Replayability

□ Different students can give different answers.

□ No obvious correct answer.

□ Can easily run for 5–10 minutes.

---

# Fun

□ Feels playful.

□ Encourages conversation.

□ Makes students want to continue.

---

# Final Test

Before approving a prompt ask:

"If I removed the title, would a teacher instantly know which engine this belongs to?"

If the answer is NO...

Rewrite it.
