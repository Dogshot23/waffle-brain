# WaffleBrain Engine Checklist

Every new prompt must pass every check before it is added to WaffleBrain.

---

# Engine

□ Is it clearly one of the 10 Waffle Engines?

□ Could a teacher identify the engine without reading the title?

□ Does it avoid introducing a second engine?

---

# World

□ Does the scenario naturally fit the chosen World?

□ Could the same engine work equally well in another World?

□ Is the World only providing the theme?

---

# Hook

□ Is the opening interesting within the first sentence?

□ Does it create curiosity?

□ Is it short?

□ Does it avoid unnecessary explanation?

---

# Ask

□ Does the Ask immediately trigger the engine?

□ Is the wording consistent with other prompts using this engine?

□ Can a teacher read it aloud exactly as written?

---

# Teacher

□ Does it explain how to run the engine?

□ Does it explain how to keep the conversation alive?

□ Does it avoid teaching language directly?

□ Is it almost identical to every other prompt that uses this engine?

---

# Quick

□ Does it naturally continue the same engine?

□ Does it avoid changing the activity?

□ Does it encourage longer speaking?

---

# Stuck

□ Does it reduce cognitive load?

□ Does it simplify without changing the engine?

□ Does it avoid introducing new ideas?

---

# Constraint

□ Does the target language match the CEFR level?

□ Will the engine naturally encourage this language?

□ Is the constraint invisible to the student?

---

# Replayability

□ Could this prompt be used multiple times?

□ Would different students produce different answers?

□ Would the same student answer differently another day?

---

# Cognitive Load

□ Is the task easy to understand?

□ Is the thinking challenge appropriate for the level?

□ Does the engine create the challenge rather than complicated instructions?

---

# Fun

□ Is the prompt likely to make students smile?

□ Does it encourage imagination?

□ Does it invite discussion rather than testing knowledge?

---

# Final Test

Ask yourself one question:

"If I changed only the nouns, would this still obviously be the same engine?"

If the answer is no...

Rewrite the prompt.

The engine should always be recognisable.
