# WaffleBrain Design Principles

## Purpose

These principles define what makes something feel like WaffleBrain.

Every prompt, engine, Route, and future feature should follow these principles.

If a new idea breaks these rules, it should be redesigned or rejected.

---

# Principle 1 — The Engine Is the Product

The conversation engine is the product.

The prompt is only an example of that engine.

A teacher should be able to replace the topic completely while keeping exactly the same conversation mechanic.

The mechanic never changes.

Only the theme changes.

---

# Principle 2 — One Engine, One Mechanic

Every Waffle uses exactly one conversation mechanic.

It should never mix multiple engines together.

For example:

✓ Keep One

✗ Keep One + Convince Me

✗ Build Together + Twist It

Teachers should instantly recognise which engine they are running.

---

# Principle 3 — Simplicity First

Every Waffle should be understandable in seconds.

Students should begin speaking almost immediately.

If the rules require a long explanation, the design is too complicated.

Complex conversations are encouraged.

Complex instructions are not.

---

# Principle 4 — Conversation Before Language

The goal is conversation.

Language development happens because students become absorbed in the conversation.

A Waffle should never feel like a grammar exercise disguised as a game.

---

# Principle 5 — Teachers Are Co-Players

Teachers do not simply read prompts.

Teachers participate.

They challenge.

They react.

They improvise.

They build ideas together with students.

The teacher is part of the conversation engine.

---

# Principle 6 — Students Create the Content

The prompt provides a starting point.

The student creates the interesting part.

Different students should produce different conversations from the same prompt.

The value comes from the interaction, not from the written prompt.

---

# Principle 7 — Replayability Matters

A Waffle should work repeatedly.

Changing the students should create a different conversation.

Changing the teacher should create a different conversation.

Changing the theme should create a different conversation.

Replayability is more valuable than novelty.

---

# Principle 8 — Low Preparation

Teachers should be able to use a Waffle immediately.

No printing.

No worksheets.

No preparation.

No explanation beyond the prompt itself.

---

# Principle 9 — One Decision at a Time

Students should never have to process multiple mechanics simultaneously.

Every engine focuses attention on one clear task.

Choose.

Rank.

Guess.

Build.

Convince.

Twist.

Change.

Continue.

The conversation grows naturally from that single decision.

---

# Principle 10 — Cognitive Load Belongs in the Conversation

Students should spend their thinking power on ideas.

Not on understanding instructions.

The interesting challenge should come after speaking begins.

Never before.

---

# Principle 11 — Teacher Recognition

Every engine should become instantly recognisable.

Experienced teachers should identify the engine within seconds.

Eventually the mechanic should become more memorable than the prompt itself.

---

# Principle 12 — Difficulty Changes the Language, Not the Game

The engine stays the same.

The conversation mechanic stays the same.

Only the language changes.

As CEFR increases:

- vocabulary becomes richer
- reasoning becomes deeper
- grammar becomes more sophisticated
- ideas become more abstract

The game itself never changes.

---

# Principle 13 — Every Prompt Must Earn Its Place

A prompt is not included because it is clever.

It is included because it demonstrates its engine exceptionally well.

If another prompt teaches the engine more clearly, replace it.

Quality always beats quantity.

---

# The WaffleBrain Test

Before adding anything to WaffleBrain, ask:

## Identity

□ Does this clearly demonstrate one engine?

□ Could a teacher identify the engine in under five seconds?

□ Would experienced users recognise the mechanic immediately?

---

## Conversation

□ Will students begin speaking within 15 seconds?

□ Can this naturally create 5–10 minutes of conversation?

□ Does it encourage interaction instead of one-word answers?

---

## Replayability

□ Would different students create different conversations?

□ Could I happily use this again next week?

□ Does changing the theme create a fresh experience?

---

## Simplicity

□ Can the teacher understand it almost instantly?

□ Is there only one conversation mechanic?

□ Are the instructions shorter than the conversation they create?

---

## Teacher Experience

□ Does the teacher participate instead of presenting?

□ Does the prompt encourage improvisation?

□ Does it reduce preparation?

---

## Final Question

If the title disappeared...

...would I still recognise which Waffle Engine this is?

If the answer is "No", redesign it.
