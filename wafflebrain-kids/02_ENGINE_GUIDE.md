# WaffleBrain Engine Guide

The ten Waffle Engines are the core product.

Every prompt in WaffleBrain is an example of one of these engines.

The engine never changes.
Only the topic, vocabulary and CEFR level change.

Teachers should recognise the engine immediately without reading the title.

---

# 1. Keep One

Core mechanic:
Present three options.
The student must keep only one and lose the others forever.

Purpose:
Decision making, justification, comparison.

Never changes:
• Three options
• One survives
• Student explains why

---

# 2. Which Is Worse?

Core mechanic:
Present two bad options.
The student chooses the less bad one.

Purpose:
Comparison, justification.

Never changes:
• Two negative choices
• No perfect answer

---

# 3. Rank It

Core mechanic:
Present several items.
Student ranks them from best to worst (or similar).

Purpose:
Comparison and discussion.

Never changes:
• Multiple items
• Complete ranking
• Defend top choice

---

# 4. One Change

Core mechanic:
Present something interesting.
Student may change ONE thing only.

Purpose:
Creativity with constraints.

Never changes:
• Exactly one change
• No extra changes allowed

---

# 5. Mystery Builder

Core mechanic:
Reveal clues one at a time.
Student updates their theory after every clue.

Purpose:
Prediction and hypothesis.

Never changes:
• Incremental clues
• Theory evolves

---

# 6. Build Together

Core mechanic:
Student creates an idea.
Teacher adds one detail.
Repeat.

Purpose:
Collaborative storytelling.

Never changes:
• Turn-taking
• Nobody finishes the story alone

---

# 7. Convince Me

Core mechanic:
Teacher deliberately disagrees.
Student must persuade.

Purpose:
Argument and persuasion.

Never changes:
• Teacher pushes back
• Student defends position

---

# 8. Twist It

Core mechanic:
Student responds.
Teacher introduces a new complication.
Repeat.

Purpose:
Flexible thinking.

Never changes:
• Situation keeps changing
• Conversation never settles

---

# 9. Emoji Spark

Core mechanic:
Three emojis inspire one idea.

Purpose:
Rapid creativity.

Never changes:
• Exactly three emojis
• One connected idea

---

# 10. Silly Reason

Core mechanic:
Present something strange.
Student invents the funniest or most unexpected explanation.

Purpose:
Creative language.

Never changes:
• No wrong answers
• Teacher accepts and builds
