# WaffleBrain Prompt Conversion Standard (WPCS)

## Purpose

The original prompts are the source of truth.

Their activities, wording, structure and teaching value have already been carefully designed.

The purpose of this conversion is NOT to improve the prompts.

The purpose is ONLY to change them from student-facing prompts into teacher-facing cue cards.

A successful conversion should feel like the original prompt viewed from the teacher's perspective, not like a newly written activity.

---

# Golden Rules

1. Preserve the learning activity exactly.

2. Preserve the original wording wherever possible.

3. Preserve the original formatting, spacing, headings and lists.

4. Only change the minimum wording necessary to change the audience.

5. If there is a choice between preserving the original wording and writing something "better", always preserve the original wording.

---

# Allowed Changes

You MAY:

• change pronouns where required

• change student-facing instructions into teacher-facing instructions

• change "Tell your teacher" into a teacher instruction

• make small grammatical changes required by the audience shift

Nothing else should change.

---

# Forbidden Changes

Do NOT:

• rewrite the activity

• expand the scenario

• simplify the scenario

• add teaching advice

• change the order of information

• merge lists into paragraphs

• remove headings

• change the student's cognitive load

• change the CEFR level

Never introduce phrases such as:

• Set the scene...

• Explain that...

• Present a change...

• Encourage the student...

• Guide the student...

• Invite the student...

• Explore...

• Find out...

unless the original prompt already contains that wording.

---

# Examples

## GOOD

Original

Your friend is visiting your town.

Choose:

• morning activity

• lunch place

Tell your teacher:

• where you go

• why your friend will like it


Teacher

The student's friend is visiting their town.

Ask the student to choose:

• morning activity

• lunch place

Then ask:

• where they would go

• why their friend would like it


---

## GOOD

Original

Describe your bedroom.

Teacher

Ask the student to describe their bedroom.


---

## BAD

Original

Describe your bedroom.

Teacher

Explore the student's bedroom.


---

## BAD

Original

Your friend is visiting your town.

Teacher

Set the scene...

Explain that...

Invite the student...

---

# Final Check

Before accepting any converted prompt, ask:

✓ Is this the same learning activity?

✓ Is the formatting recognisably the same?

✓ Have I preserved the original wording wherever possible?

✓ Have I changed only the audience?

If the answer to any question is NO, revise the prompt before continuing.
