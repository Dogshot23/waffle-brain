# Waffle Brain A1/A2 Prompt Bank

## Purpose

This document contains the approved A1/A2 speaking activities that will become the Waffle Brain prompt system.

Prompts are created from the category design rules.

They are not conversation questions.

They are teacher-led speaking activities.

## Categories

Everyday Situations
Simple Roleplay
Describe
Explain and Show
Choose and Create
Guided Stories


## Prompt requirements

Every prompt must:

- be written for the teacher
- create 1 to 5 minutes of speaking
- have a clear situation or goal
- reduce cognitive load
- avoid one-word answers
- avoid generic ESL questions
- be possible for A1/A2 students


## Prompt format

Each prompt should contain:

Title

Teacher instruction

Student task

Constraint/support

Language focus
